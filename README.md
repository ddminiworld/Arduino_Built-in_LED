# 🔦 Arduino_Built-in_LED
This project demonstrates how to blink an LED using an Arduino board.  
It uses the built-in LED connected to **digital pin 13**, so no external components are required.

---

## 🚀 Features
- Uses Arduino built-in LED
- Beginner-friendly project
- Demonstrates digital output control
- Simple and easy to understand code

---

## 🧰 Requirements
- Arduino board (Uno, Nano, etc.)
- USB cable
- Arduino IDE

---

## 🔌 Circuit Diagram
No external circuit required.  
The built-in LED is internally connected to **pin 13**.
